# WhatsApp UI - Flutter

Replicating the WhatsApp chat screen (dark mode) in Flutter.

## Demo Video
[Watch the demo video](https://drive.google.com/file/d/1XHNXvLfAb9ky4pb1fSN0LjM2DNeJ1Xno/view?usp=sharing)

## Features
- Custom AppBar (profile picture, user name, call/video icons, options menu)
- Incoming and outgoing message bubbles
- Input bar with camera icon, send icon, and mic button
- Dark chat background

## Run the project
flutter pub get
flutter run
